# Git в Visual Studio Code

Удобные возможности VS Code:

1. Панель Source Control показывает измененные и неотслеживаемые файлы в одном месте.
2. Встроенный редактор diff наглядно отображает добавленные и удаленные строки.
3. GitLens показывает авторов строк, историю изменений и сведения о коммитах.

В терминале удобнее просматривать всю историю веток командой `git log --oneline --all --graph`.
